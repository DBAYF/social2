# Backend: Lovable

This project does **not** use Firebase Functions. Backend features (AI, etc.) run on **Lovable**.

- **Firebase** is used only for: Auth, Firestore, Storage.
- **Lovable** hosts the API that the frontend calls with the Firebase ID token.

See **[../LOVABLE_BACKEND.md](../LOVABLE_BACKEND.md)** for the API contract and what to implement on Lovable before launch.
